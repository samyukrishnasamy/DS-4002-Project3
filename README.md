# DS-4002-Project3

# Diffusion vs. Convolutional Autoencoders for Fluid Flow Reconstruction

This repository contains the work for a DS-4002 project comparing a **Diffusion Autoencoder (DAE)** and a **Convolutional Autoencoder (CAE)** on 2D turbulent fluid flow data derived from the Navier–Stokes equations.

Our research question is:

> How does the Diffusion Autoencoder’s step-by-step denoising process affect the accuracy of reconstructing turbulent fluid flows compared to a Convolutional Autoencoder?

We hypothesize that the DAE will reconstruct turbulent flows more accurately than the CAE, especially for high-frequency structures and small-scale vortices, as measured by structural similarity (SSIM).

---

## Contents of the Repository

This repository is organized to make it easy for another user to understand the project, access the data, and reproduce the results.

It currently contains:

- **DATA/**  
  - Raw fluid simulation data files (Navier–Stokes turbulence) in `original_data/`.  
  - A `README.md` with dataset metadata (summary, provenance, license, ethical statement, and data dictionary).

  - A single exploratory Jupyter notebook: `00_exploratory_analysis.ipynb`, which performs exploratory data analysis (EDA) on the dataset.

- **OUTPUTS/**  
  - A folder `00_exploratory_analysis/` with figures generated by the EDA notebook:
    - `hf_energy_ratios.png` — high-frequency energy ratios by channel.
    - `mean_std_vs_re.png` — mean and standard deviation of each channel across Reynolds numbers.

- **README.md (this file)**  
  - Orientation to the repository, folder map, and instructions to reproduce the results.

## Section 1: Software and Platform

### Software

This project is implemented in **Python** using **Jupyter Notebook**.

- **Python version:** 3.11 (compatible with 3.10+ if dependencies are satisfied)
- **Notebook environment:** Jupyter Notebook or JupyterLab

### Key Python Packages

The main add-on packages used for this project are:

- `numpy` – handling `.npy` files, numerical operations
- `pandas` – organizing metadata, simple tabular summaries
- `matplotlib` – creating exploratory plots and visualizations
- `torch` – (for later modeling steps) deep learning framework for CAE/DAE
- `torchmetrics` – computing metrics such as SSIM and PSNR
- `tqdm` – progress bars for longer computations
- `scipy` – additional numerical utilities (e.g., interpolation if needed)
- `einops` – clean tensor reshaping and rearrangement for model inputs

All dependencies are listed in `requirements.txt`.

### Platform

- **Development platform:** macOS  
- **Compatible platforms:** macOS, Windows, and Linux (as long as Python and the listed packages are installed)

For best performance on future model training (CAE/DAE), a **GPU** (CUDA/MPS) is recommended, but the exploratory notebook can run on CPU.

## Section 3: Instructions for Reproducing the Results

This section explains, step-by-step, how to reproduce all results currently in the repository including: 

- EDA Plots
- CAE preprocessing, training, and intermediate outputs
- DAE preprocessing, training, sampling, and final comparison
- CAE vs. DAE visual + written comparison files

These instructions assume basic familiarity with running Jupyter Notebooks.

---

### **Step 0: Clone the Repository**

Open a terminal (or PowerShell on Windows) and run:

```bash
git clone https://github.com/samyukrishnasamy/DS-4002-Project3.git
cd DS-4002-Project3

### **Step 1: Set Up the Python Environment**

Create and activate a virtual environment (recommended but not required).

- macOS / Linux:

python3 -m venv .venv
source .venv/bin/activate


- Windows (PowerShell):

py -m venv .venv
.venv\Scripts\Activate.ps1


Install the required Python packages:

pip install -r requirements.txt

### **Step 2: Obtain the Dataset**

This project uses the **Navier–Stokes 2D Turbulence Dataset**, publicly available on Zenodo.

1. Open the dataset page:  
   [https://zenodo.org/records/13909869  ](https://zenodo.org/records/13909869)

2. Download the `.npy` files corresponding to the turbulence simulations.

3. Place the downloaded `.npy` files into the following folder inside the repository:

If needed, consult `DATA/README.md` for dataset details, license (CC-BY-4.0), and file structure.

### **Step 3: Launch Jupyter Notebook**

From the root of the repository (`DS-4002-Project3`), start Jupyter:

```bash
jupyter notebook
or
jupyter lab
```

### Step 4: Configure Any Necessary Paths (If Applicable)

The notebook expects the dataset to be located in:

```DATA/OriginalData/```

- If your folder structure matches the repository, **no changes are required**.
- If your data is stored elsewhere, update the data-loading cell inside the notebook so that it points to the correct directory before running any analysis.

### **Part A: Reproducing the Exploratory Data Analysis (EDA)**

Inside the notebook **`00_exploratory_analysis.ipynb`**:

1. Run all cells from top to bottom  
   *(Kernel → Restart & Run All, or run cells sequentially)*

2. The notebook will automatically:

   - Load the `.npy` dataset files  
   - Confirm the dataset shape: **(T, C, H, W) = (39, 4, 128, 256)**  
   - Compute the mean and standard deviation for each channel across Reynolds numbers  
   - Compute high-frequency energy ratios for each channel  
   - Generate and save two exploratory plots  

When complete, the notebook will generate the following files:

OUTPUTS/
└── 00_exploratory_analysis/
├── hf_energy_ratios.png
└── mean_std_vs_re.png

### **Step A2: Verify EDA Output**
- confirm that:
- Both images were generated
- High-frequency energy patterns match expected physics
- Mean/std trends resemble the GitHub versions

If so, the EDA reproduction is complete.

### **Part B — Reproducing the CAE Pipeline**
Notebook:

```SCRIPTS/01_CAE_pipeline.ipynb```

This pipeline handles CAE preprocessing, normalization, training, and initial reconstructions.

Run all cells. The notebook will:

- Load train/test turbulence frames
- Normalize them
- Train a Convolutional Autoencoder
- Compute metrics (MSE, SSIM, PSNR)

Save outputs to:
```OUTPUTS/01_CAE_pipeline_outputs/```
Currently in the repo:
```ns_norm_stats.npz```    # normalization statistics used by both CAE & DAE

### **Step B2: Verify CAE Output**
```OUTPUTS/01_CAE_pipeline_outputs/ns_norm_stats.npz```
These stats are required for the DAE pipeline to maintain consistent preprocessing.

### **Part C — Reproducing the DAE Pipeline**
Notebook:
```SCRIPTS/02_DAE_pipeline.ipynb```
